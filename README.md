## Возможности

| Вкладка | Что делает |
| --- | --- |
| **ВкусБэк** | Считает ВкусБэк по табличному чеку. |
| **Очистка текста** | Убирает лишнее из текста в реальном времени. |
| **Срок годности** | Считает, до какого числа годен продукт. Поле даты умное: точки ставятся сами, есть кнопка «Вчера» и календарь, недостающие месяц и год подставляются при выходе из поля, результат виден сразу. |
| **Срочные: замены** | Сверяет распределение от бота с графиком операторов и предлагает замены. |

Данные ВкусБэка, очистки текста и срока годности не уходят на сервер и сохраняются только в браузере. Вкладка «Срочные» обращается к Google Sheets, поэтому ей нужен интернет.

Если что-то пошло не так, внизу любой страницы есть незаметная ссылка «Скопировать отчёт о работе». Отчёт содержит версию, браузер и ход работы сайта, но не ваши тексты, ФИО и теги; его можно отправить разработчику.

## Срочные: как это работает

1. Вставьте текст бота «Дежурные на линию «Срочные»» (поздние или ранние).
2. Выберите дату (по умолчанию завтра).
3. Сайт читает график только на чтение, считает срочные выходы (ячейки с фиолетовой заливкой) и для тех, у кого их много, подбирает людей с той же сменой и меньшим числом срочных.
4. Вы получаете таблицу «кто → кто» со счётчиками и готовый текст с ФИО и тегами.

Правила подбора:
- рассматриваются только команды 1–4;
- лидеры и временные лидеры никогда не назначаются и не заменяются;
- новички (имя залито светло-зелёным в графике) в замены не попадают;
- один человек не попадает в список дважды;
- команды и лидеры читаются из таблицы при каждом расчёте, поэтому изменения в графике учитываются сами.

## Разработка

Стек: Vite, TypeScript, vitest. Код разделён на слои: `src/domain` (чистая логика), `src/application` (сценарии), `src/infrastructure` (Google Sheets, хранилище), `src/ui` (контроллеры, шаблон, отрисовка) и `src/styles` (дизайн-система: токены, светлая и тёмная темы). Шрифт Nunito входит в сборку.

```bash
npm install
npm run dev        # локальный сервер
npm run test:all   # тесты, типы, сборка, покрытие, прогон в нескольких часовых поясах
```

### Ключ для «Срочных»

Вкладка читает таблицу через Google Sheets API (только чтение). В репозитории ключа нет: при деплое он берётся из секрета GitHub Actions `SHEETS_API_KEY`. В собранном сайте ключ виден в браузере, поэтому в Google Cloud он должен быть ограничен: только Google Sheets API и только HTTP referrers сайта (на localhost такой ключ не работает). Для локальной разработки задайте свой ключ в `.env.local` (файл не попадает в git):

```bash
VITE_SHEETS_API_KEY=ваш_ключ
```

### Выпуск версий

Изменения идут через pull request в `main`, прямых пушей нет. Версии по [SemVer](https://semver.org/lang/ru/), на каждую версию ставится тег `vX.Y.Z`. После слияния GitHub Actions прогоняет тесты, собирает сайт и публикует его на GitHub Pages.
