<p align="center">Набор небольших рабочих инструментов в браузере: разбор чека и ВкусБэк, очистка текста и срок годности.</p>

## Возможности

| Вкладка | Что делает |
| --- | --- |
| **ВкусБэк** | Считает ВкусБэк по табличному чеку. |
| **Очистка текста** | Убирает лишнее из текста в реальном времени. |
| **Срок годности** | Считает, до какого числа годен продукт. Поле даты умное: точки ставятся сами, есть кнопка «Вчера» и календарь, недостающие месяц и год подставляются при выходе из поля, результат виден сразу. |

Данные не уходят на сервер и сохраняются только в браузере.

Если что-то пошло не так, внизу любой страницы есть незаметная ссылка «Скопировать отчёт о работе». Отчёт содержит версию, браузер и ход работы сайта, но не ваши тексты, ФИО и теги; его можно отправить разработчику.

## Разработка

Стек: Vite, TypeScript, vitest. Код разделён на слои: `src/domain` (чистая логика), `src/application` (сценарии), `src/infrastructure` (хранилище, буфер обмена, журнал), `src/ui` (контроллеры, шаблон, отрисовка) и `src/styles` (дизайн-система: токены, светлая и тёмная темы). Шрифт Nunito входит в сборку.

```bash
npm install
npm run dev        # локальный сервер
npm run test:all   # тесты, типы, сборка, покрытие, прогон в нескольких часовых поясах
```

### Выпуск версий

Изменения идут через pull request в `main`, прямых пушей нет. Версии по [SemVer](https://semver.org/lang/ru/), на каждую версию ставится тег `vX.Y.Z`. После слияния GitHub Actions прогоняет тесты, собирает сайт и выкладывает его на сервер sanlover.ru.
