## Summary

Дизайн в целом соответствует брифу и референсу: единый язык карточек, зелёный акцент, тёмная тема осмысленная, на телефоне нет горизонтального скролла. Ревью нашло 1 критичную проблему доступности (слабый фокус) и 1 поломку навигации на планшете; всё исправлено в этой же ветке.

## Must Fix (исправлено)

1. **Кольцо фокуса почти невидимо.** Было `0 0 0 3px rgba(31,122,52,.28)`, контраст с белым ≈ 1.4:1 (нужно ≥ 3:1). `src/styles/tokens.css`. _Fix: сплошное двойное кольцо `0 0 0 2px surface, 0 0 0 4px accent`._
2. **Навигация на планшете 768px ломала слова** («ВкусБэ/к», «Срочны/е»): четыре пилюли + логотип не помещаются. `src/styles/layout.css`. _Fix: верхняя навигация только с 1024px, ниже — нижняя панель вкладок; `nowrap` для подписей._

## Should Fix (исправлено)

1. **Цели касания меньше 44px:** `summary` «Показать товары»/«Лог работы» (32px), кнопка копирования кэшбэка (32px), пилюли вкладок на десктопе (40px). _Fix: 44px._
2. **Тело текста 15px на телефоне** (по гайду ≥ 16px). _Fix: 16px до 768px, 15px выше._
3. **Подписи нижней панели 11px.** _Fix: 12px._
4. **Порядок заголовков:** карточки-счётчики использовали `h3` без `h2` (h1 → h3). _Fix: `p.kpi-label`._
5. **Копирование в «Срочных» недоступно с клавиатуры:** ФИО и тег были `span` без фокуса. _Fix: `button type=button` с подсказкой._
6. **Неверная роль ARIA:** `aria-selected` на кнопках без `role=tab`. _Fix: `aria-current="page"`._
7. **Таблица «Срочных» на телефоне через `max-width`.** _Fix: mobile-first, карточки по умолчанию, таблица с 640px._

## Could Improve (не делал)

1. Вспышка светлой темы при загрузке у пользователей тёмной системной темы: тема применяется скриптом после первой отрисовки (inline-скрипт запрещён CSP; нужна вторая копия токенов под `prefers-color-scheme`).
2. Поля для вставки чеков и текста бота моноширинные (нужно для колонок); при желании можно сделать обычным шрифтом.
3. Инлайн-кнопки копирования ФИО/тега в плотной таблице меньше 44px (допустимо для строчных элементов, но на телефоне удобнее увеличить).
4. Firefox, Safari/iOS и реальный телефон не проверены в этой среде.

## What Works Well

- Карточки-счётчики с иконками в цветной плитке: близко к референсу и читаются с первого взгляда.
- Таблица «Было → Станет» на телефоне превращается в понятные карточки без горизонтального скролла.
- Токены: светлая и тёмная палитры осмысленные, контраст текста ≥ 4.5:1, акцент светлее в тёмной теме.
- Нижняя панель вкладок с иконками и safe-area, скролл-кнопка и уведомления поднимаются над ней.
- Мягкий шрифт Nunito без резких начертаний, `prefers-reduced-motion` и `forced-colors` учтены.
