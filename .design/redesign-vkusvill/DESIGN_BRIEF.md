# Design Brief: Редизайн сайта ВВТулка (зелёная тема ВкусВилла)

## Goal
Перенести язык референса (AssetTrack dashboard) на все 4 вкладки сайта: светлый нейтральный фон, белые карточки с тонкой рамкой, верхняя панель с навигацией-пилюлями, карточки-счётчики с иконками, аккуратные таблицы. Зелёные цвета ВкусВилла. Удобно на телефоне и одинаково в браузерах.

## Users and context
Сотрудники поддержки: быстрые рабочие операции (разбор чека, очистка текста, срок годности, подбор замен на срочные). Часто с телефона, часто в потоке задач: важны скорость чтения, крупные цели касания, копирование в один клик.

## Aesthetic philosophy
Dieter Rams (функционализм) + мягкость Scandinavian: один функциональный акцент (зелёный), тонкие границы вместо теней, строгая 4/8px-сетка, минимум декоративного, округлый Nunito без резких начертаний (жирность ≤ 700).

## Design decisions
- Навигация: сверху (пилюли) на ≥768px, нижняя панель вкладок на телефоне.
- Токены светлой и тёмной тем (`src/styles/tokens.css`), контраст WCAG AA.
- Карточки-счётчики: «ВкусБэк» (заказы, сумма, кэшбэк), «Срочные» (всего дежурных, замен, без замены).
- Таблица «Срочных» на телефоне — карточки «Было → Станет».
- Иконки SVG вместо emoji.

## Constraints
Vite + TypeScript, статический сайт на GitHub Pages, CSP `script-src 'self'`; шрифт только из сборки; стандартный CSS без экспериментальных возможностей; не переименовывать id и классы, которые использует код.

## Success criteria
- Нет горизонтального скролла на 375px; цели касания ≥ 44px; поля ввода 16px.
- Контраст текста ≥ 4.5:1 в обеих темах; видимый фокус у всех интерактивных элементов.
- Все 4 вкладки в одном стиле, светлая и тёмная темы.
